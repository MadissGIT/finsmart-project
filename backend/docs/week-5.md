# Неделя 5 Стабилизация бэкенда

Новые методы используют Bearer-токен. Все пути указаны относительно /api/v1.

| Метод | Возможность |
| --- | --- |
| GET /transactions | Совмещает существующие фильтры дат с category_id, operation_type и q. Поиск q ищет буквальную подстроку по контрагенту и исходному описанию. |
| GET /analytics/expenses/trend | from_date и to_date включительно, до 367 календарных дней. group_by=day или week. Неделя начинается в понедельник, пустые интервалы имеют сумму 0. |
| GET /discounts/recommended | Действующие офферы из трёх категорий с наибольшими расходами за предыдущие 30 календарных дней, включая сегодня. Без расходов результат пуст. |
| GET /goals/{id}/contributions | История взносов своей копилки с суммой, источником и временем. limit до 100, offset от нуля. |
| PATCH /users/me | Изменение имени через поле full_name. |

Миграция 0006_query_indexes добавляет индекс транзакций по владельцу,
категории и дате и индекс истории взносов по цели и времени. Для расчёта
целей исключаются строки взносов после конца выбранного периода до агрегации.
График и топ категорий агрегируются в PostgreSQL.

## Production Compose

Используется отдельный compose.production.yaml. Через окружение процесса
или хранилище секретов деплоя задайте следующие переменные.

- FINSMART_POSTGRES_PASSWORD — пароль пользователя finsmart.
- FINSMART_DATABASE_URL — DSN PostgreSQL с этим паролем, хостом db и базой finsmart.
  Специальные символы в пароле в составе DSN должны быть URL-кодированы.
- FINSMART_JWT_SECRET — постоянный случайный ключ от 32 символов. Его смена
  аннулирует выпущенные токены.
- FINSMART_CORS_ORIGINS — JSON-массив разрешённых origin frontend.
- FINSMART_API_PORT — внешний локальный порт API, по умолчанию 8000.

```sh
docker compose -f compose.production.yaml up --build --wait --wait-timeout 180
```

Сервис migrate завершает обновление схемы до старта API. PostgreSQL не
публикует порт, API доступен на loopback для HTTPS-прокси. Корневая файловая
система API доступна только на чтение, для временных файлов используется /tmp.
Ошибки недоступности БД возвращают 503. В лог пишутся метод, шаблон маршрута
и класс ошибки. Access log Uvicorn в production выключен.

CI запускает сквозную проверку регистрации, импорта и повторного импорта,
дашборда, диагноза, скидок, создания и пополнения цели, истории взносов,
ротации токена и CRUD. Отдельный job проверяет production Compose и
валидность токена после перезапуска API.

Каталог по-прежнему содержит демонстрационные офферы. Пять записей в
локальном smoke-сценарии не подтверждают ежедневную доступность пяти
реальных предложений. Для проверки точности на реальных операциях нужен
размеченный набор. Развёртывание на хостинг и задачи шестой недели отдельные.
