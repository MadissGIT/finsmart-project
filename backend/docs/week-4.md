# Неделя 4 Каталог и достижения

Реализованы контрольные точки Backend из раздела 5 документа недели 4.
Frontend и движок микро-челленджей в эту поставку не входят.

## Каталог

Миграция 0005_catalog загружает 35 офферов из seeds/discounts.json.
ID стабильны, каталог доступен через GET /api/v1/discounts.
Фильтр category_id необязателен. Истёкшие предложения не выдаются.
Для бессрочных предложений используется дата 9999-12-31.

Офферы предоставлены аналитиком для демонстрации. is_demo=true указывает,
что действительность промокодов не подтверждалась партнёрами. affiliate_url
пустой: документ не содержит проверенных ссылок. Рублёвая выгода, бонусы,
подарки и ограничения сохранены в benefit, activation и conditions.
discount_percent используется только как числовая характеристика; для
рублёвого оффера это 0, а не отсутствие выгоды. Не следует сравнивать
разные механики только по этому числу.

## Статьи

GET /api/v1/articles возвращает десять статей из документа, включая полный
текст и чек-листы. GET /api/v1/articles/art-01 возвращает одну статью.
Неизвестный ID — 404. Теги соответствуют категориям статей из источника:
например, ?tags=Оптимизация%20расходов. Несколько параметров tags
сочетаются по AND. Пагинация: limit=20 (1–100), offset=0.
Статьи предоставлены аналитиком, финансовые примеры не являются проверкой
текущих тарифов и условий банков.

## Достижения

GET /api/v1/achievements требует Bearer-токен и возвращает каталог десяти
бейджей, earned_at, unlocked и сумму reward_points. В этой поставке
автоматически выдаются:
- BADGE_FIRST_IMPORT — первый импорт с новыми операциями;
- BADGE_PIGGY_CREATED — первая созданная копилка;
- BADGE_FIRST_DEPOSIT — первый успешный взнос;
- BADGE_GOAL_REACHED — достижение целевой суммы.

Выдача происходит в той же транзакции БД, что сохранение операции.
Составной первичный ключ защищает от повторной награды. Удаление копилки
не удаляет уже полученный бейдж. Награды не прибавляются к диагностическому
Health Score: reward_points показываются отдельно.

Остальные шесть бейджей доступны как заблокированные определения каталога.
Их триггеры (периодические проверки месяца, применение промокода,
отключение подписки, микро-челлендж) требуют отдельных событий и относятся
к следующему расширению. Ручного API самоначисления наград нет.

Проверки: just check и just migration-check через Docker. Seed-файлы
копируются в образ вместе с кодом. Миграция обратима.
