# ФинСмарт Frontend

React 18 + TypeScript + Vite + Tailwind. Мобильные экраны Welcome, регистрации,
профиля, успешной регистрации, первичной настройки и Dashboard по Figma.

## Запуск

Нужны Git, Node.js 24 и npm.

```bash
git clone --branch frontend-onboarding https://github.com/MadissGIT/finsmart-project.git
cd finsmart-project/frontend
npm ci
npm run dev
```

Открыть [Welcome](http://127.0.0.1:5173/welcome) или
[Dashboard](http://127.0.0.1:5173/). Для просмотра интерфейса backend не требуется.

## Экраны

| Экран | Адрес | Что работает |
| --- | --- | --- |
| 01 Welcome | `/welcome` | Регистрация, демовход и переход к обзору |
| 02 Регистрация | `/register` | Email, пароль, подтверждение, согласие, показ пароля, ошибки полей |
| 03 Ввод данных | `/register/profile` | Имя, дата рождения, выбор цели и дохода, пропуск |
| 04 Успешная регистрация | `/register/success` | Переход к настройке или обзору |
| 05 Первичная настройка | `/setup` | Выбор CSV/XLSX до 10 МБ и пропуск |
| 06 Dashboard | `/` | Приветствие, пустые состояния баланса, расходов, графика, рейтинга, бюджета и целей |

Профиль и демонстрационный вход — `/auth`. Дополнительные разделы и проверка
API — `/more`. Аналитика — `/analytics`. `/transactions`, `/goals` и `/discounts`
пока показывают заглушки. Неизвестный адрес открывает 404.

На телефоне используется нижняя навигация: Обзор, Транзакции, Копилки,
Скидки, Ещё. От 768px виден Sidebar. Формы на широком экране остаются
в центральной колонке; Dashboard использует доступное пространство.

## Границы демонстрации

Регистрация и вход не создают аккаунт и не обращаются к auth API.
Google-вход показывает объяснение, что интеграция ещё не подключена.
Ссылки условий открывают описание демоверсии, не готовые юридические документы.

В `sessionStorage` текущей вкладки сохраняются email, имя, выбранные цель,
диапазон дохода и этап сценария. Пароль и дата рождения не сохраняются
и не отправляются на сервер. «Сбросить демо» в профиле очищает эти данные.
Если storage недоступен, сценарий работает в памяти.

Выбор выписки проверяет расширение и размер, показывает имя файла.
Содержимое не читается и не отправляется: импорт ещё не подключён.
Выбор файла не заполняет Dashboard данными.

Dashboard и аналитика открываются без финансовых данных: суммы и рейтинг
обозначены прочерками, график и список целей пусты. Приветствие использует
только введённое пользователем имя; без имени показывается «Привет!».
Выбор диапазона дохода или цели при регистрации не создаёт операций и копилок.
Ручной ввод, расчёт финансовых показателей и загрузка личной статистики
будут подключены на следующем этапе.

Источник дизайна и иллюстраций: [docs/design.md](docs/design.md).

## Существующий API

Общий axios-клиент: `src/shared/api/client.ts`, `baseURL: '/api/v1'`,
таймаут 10 секунд. Vite перенаправляет `/api` на `http://127.0.0.1:8000`
с сохранением пути. Например:

```text
127.0.0.1:5173/api/v1/health/ready
    → 127.0.0.1:8000/api/v1/health/ready
```

Для реальной проверки запустить backend по его README, открыть `/more`
и нажать «Проверить подключение». Вызываются два реализованных endpoint:

- `GET /api/v1/health/ready` — готовность backend и БД;
- `GET /api/v1/categories` — справочник категорий.

Полученные категории можно раскрыть после успешной проверки.
При 503, сетевой ошибке или неожиданном JSON показывается сообщение,
доступна повторная проверка.

Для другого адреса backend скопировать `.env.example` в `.env.local`,
изменить `API_PROXY_TARGET` и перезапустить Vite. Для работы через dev-прокси
дополнительный CORS не нужен. Эта переменная не попадает в клиентский JS.

Будущий `getDashboard()` в `entities/analytics/api.ts` пока не вызывается:
endpoint аналитики не подключён. [Контракты API](docs/api-contracts.md).

## Структура

```text
src/
  app/        # маршруты, стили, провайдеры
  pages/      # экраны приложения
  widgets/    # каркас, этапы регистрации, график, бюджет, копилка
  features/   # демонстрационное состояние, проверки форм и API
  entities/   # DTO и запросы предметных областей
  shared/     # axios-клиент, поля, диалог, логотип, форматирование
public/
  illustrations/ # локальные PNG для трёх экранов
```

Упрощённый FSD: `app → pages → widgets → features → entities → shared`.
Алиас `@/` настроен в TypeScript и Vite. Стили — `app/styles.css`.
Inter поставляется локально через `@fontsource-variable/inter`.

## Проверки

Из папки `frontend`:

```bash
npm run lint
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E сами запускают Vite на 5173 и тестовый HTTP upstream на 18080.
Порты должны быть свободны. Проверяются регистрация, ошибки полей,
сохранение прогресса, отсутствие пароля в storage, прямые адреса и обновление,
ширина 320px, пустые состояния, диалоги, навигация, выбор файла и API через dev-прокси.

Тестовый upstream не является FastAPI. Эти тесты подтверждают связку
браузер → axios → Vite → HTTP, но не работу FastAPI с PostgreSQL.
Реальный backend проверяется отдельно кнопкой на `/more`.

GitHub Actions запускает проверки для `frontend-*`, `main` и pull request.
При ошибке браузерных тестов сохраняются traces.

## Размещение

`npm run build` создаёт `dist/`, `npm run preview` показывает собранную статику.
На production-сервере нужно отдельно направить маршруты SPA в `index.html`,
а `/api/*` — на backend: dev-прокси Vite не входит в `dist/`.
